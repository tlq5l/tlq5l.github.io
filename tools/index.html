Tools

Public tools published on GitHub by tlq5l. Each entry links to its repository, where the code and license are.

agentic-video

agentic-video lets an AI agent that reads text and images, but not video, work with video files on your own machine.

License: MIT. Repository on GitHub

afk-timer

A small Claude Code mod that tells you, above the prompt, how long you have been away and whether the session's prompt cache has likely expired.

License: MIT. Repository on GitHub

claude-guards

Free guards for Claude Code: three hooks that check Bash commands before they run (git data loss, purchases, test failures hidden by a pipe), plus a streamline skill that trims finished work.

License: MIT. Repository on GitHub

shopify-schema-audit

Checks what a live store actually serves and tells you what Google Search Console (and EU/accessibility rules) will complain about.

License: MIT. Repository on GitHub

Privacy policy: gog CLI

Last updated: 25 October 2026

Who this covers

"gog CLI" is a Google sign-in for Terry's personal command-line tools, built on the open-source gogcli. Only Terry's own Google accounts use it. It is not offered to the public.

What data it accesses

With the account owner's permission, the tools can read and change data in that owner's Google account through Google's APIs, for the services the owner approved (for example Gmail, Calendar, Drive, Docs, Sheets and Contacts).

How the data is used

  • Only to carry out tasks the account owner asks for, such as reading, sending or organising their own email and files.
  • Requests run on the owner's own computer. Sign-in tokens are stored on that computer only.
  • The owner may pass data to AI assistants they use (such as Claude) to carry out their own requests.
  • Data is not sold, used for advertising, or shared with anyone else.

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Removing it stops all further access.
